# 毕设答辩说明

## 项目名称
软件设计师 AI 自适应学习 Agent

## 目标
将大语言模型、RAG 知识库和学习行为分析结合，构建能够根据用户实际学习情况动态调整学习内容的智能学习系统。

## 主要功能
1. 知识库管理
2. AI知识库问答
3. AI专项训练
4. 自动判题与解析
5. 错题管理
6. 间隔复习
7. 自适应学习分析
8. 每日学习任务
9. 学习报告
10. 云端数据存储

## 推荐演示顺序
首页 → 知识库问答 → AI专项训练 → 错题记录 → 错题分析 → 自适应分析 → 学习报告。

## 创新点
- 大模型 + 专业知识库
- 学习行为驱动的自适应计划
- 错题到复习再到重新评估的闭环
- 云端数据与 Web 使用

## 答辩总结
系统将 LLM、RAG、向量检索、数据库和自适应学习机制结合，实现了一个完整的智能学习应用原型。
